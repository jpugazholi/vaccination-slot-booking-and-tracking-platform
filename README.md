# Vaccination Slot Booking and Tracking Platform

## 📌 Project Overview

The Vaccination Slot Booking and Tracking Platform is a web-based application that allows users to find available vaccination slots, book appointments, and track their vaccination booking status.

Administrators can manage vaccination centers, vaccines, available slots, and user bookings through an admin dashboard.

## 🎯 Objectives

- Allow users to register and login securely.
- Display available vaccination centers and slots.
- Allow users to book vaccination appointments.
- Allow users to track and manage their bookings.
- Allow administrators to manage vaccination centers, vaccines, slots, and bookings.

## 👥 User Roles

### User
- Register and login
- View vaccination centers
- Search available slots
- Book vaccination slots
- View booking status
- Manage profile

### Admin
- Login securely
- Manage vaccination centers
- Manage vaccines
- Manage vaccination slots
- View and manage bookings
- Manage users
